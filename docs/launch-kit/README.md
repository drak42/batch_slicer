# Launch kit

Drafts and notes for announcing BatchSlicer: forum and Reddit posts, replies,
awesome-list entries, which pictures to use and where to post. Each draft has
a copy button.

- `index.html` is the kit. Open it in a browser. It is also published as a
  private Claude artifact, "BatchSlicer Launch Kit"; this file is its source,
  so edit it here and republish the artifact from it.

Keep it in step with releases: when a default or an option changes, check the
drafts still to post (the main post, the CFS post, the short post) and add a
follow-up reply for the forum threads if users would notice.

This folder is not part of the package (see `MANIFEST.in`).
